# 英语有续集

English: To Be Continued

把高中英语词汇编入同一组人物的连续故事。第一册采用《我被自己的分身卷了》的校园轻科幻喜剧，依据北师大版英语必修第一册。

主人公叫“小帅”，英文对白写作 `Xiaoshuai`；复制体称“小帅的分身”或“分身”。

每集采用英文解说，HTML 中提供可直接朗读的英文解说稿，以及逐句对应的英文字幕和简体中文字幕。配音与字幕时间轴由视频制作项目完成。

教材目录：`/Users/huyin/Desktop/Niki/教材/英语`。当前先做第一册，使用该目录中的 `北师大版·英语必修 第一册.pdf`。项目规则记录在 [AGENTS.md](AGENTS.md)。

本项目为抖音账号「英语有续集」准备故事与学习素材 HTML，以及头像、主页背景等配套图片；视频将在另一个项目中制作。**一集一个独立 HTML，每个文件必须包含完整剧本、图片和学习的单词。**

第一集包含 8 幅漫画图片、完整双语剧本，以及 5 个学习单词的词义、例句和中文解释，可离线打开。制作源文件与重建方法见 [第一集制作说明](production/book-01/ep-001/README.md)。

2026-11-06，第一集首屏按用户“不连贯”的反馈改为 16 秒连续动作预演：固定同一教室镜头，用同一人物素材完成老师提问、分身举手、小帅在门外探头。预演包含音效与原文双语字幕，可暂停、重播、拖动和离线使用；当前仍是二维剪纸式动作预演，正式英文配音和完整动画制作由视频项目完成。

第 001—015 集均已补齐抖音发布区：标题最多 30 字，简介连同话题最多 1000 字，最多 5 个话题，恰好 30 个不重复的备用关键词，以及内嵌且可离线下载的横版 4:3、竖版 3:4 封面。查看[发布限制、话题调研与资料总览](docs/book-01-publishing.md)，可打开各集 HTML、封面和生成提示词。后续新集沿用生成校验，并搜索当期有效、适合本集的官方活动；未核实活动不写成官方扶持话题。
