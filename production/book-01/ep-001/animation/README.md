# 第一集 16 秒连续动作试演

样片内嵌在本集唯一 HTML `episodes/book-01/ep-001.html`，不另建一份独立分集 HTML，不输出视频。

2026-11-06 根据用户“不连贯”的反馈，替换此前的 30 秒多镜头拼接样片。旧版在保证、举手与反应之间切换整张姿势图，人物比例与肩部位置改变，网页功能通过检查不代表动作自然。当前只验证第 4 格的一段连续举手表演。

## 连续性处理

- 全程固定教室与走廊构图，没有场景切换、突然放大、切换人物全身图或结尾题字遮幕。
- 分身使用一套固定的身体与脸；左右上臂、前臂、手掌独立，围绕肩、肘、腕连续转动。关节角度采用平滑时间曲线，上臂先起、前臂稍跟随，人物的身高、头部和身体锚点保持一致。
- 班主任始终在右侧；红内搭小帅只在左侧走廊探头，没有进入教室。
- 背景与部件准备后缓存，每帧直接绘制少量图层，移除旧版每帧数百条纹理拼接。
- 结尾停在同一画面，可拖动查看动作前后的连续位置。系统减少动态偏好下省略次要摆动，保留用户主动播放的举手动作。

## 内容与声音

| 时段 | 剧情 | 原文解说 |
| --- | --- | --- |
| 0—4 秒 | 老师提问，分身准备举手 | EN008 |
| 4—8 秒 | 连续举手，出现 volunteer | EN009 |
| 8—12 秒 | 保持举手，说出 goal；小帅从走廊探头 | EN010 |
| 12—16 秒 | 维持同一空间关系，以小帅的反应收尾 | EN011 |

全部中英字幕由构建脚本根据 `source` 从 `episode.json` 读取，英文与原文完全一致。试演时序供动作节奏参考，正式配音后需重新定时，不是成片字幕时间轴。

当前有浏览器本地合成的轻音乐与动作音效，没有英文台词音频。正式英文解说使用小帅已选定音色；人物试听用于声音参考，不替代本集配音。

## 源文件与素材

- `scene.js`：固定镜头、部件准备、肩肘腕绘制与连续动作曲线。
- `player.js`：音效、播放状态、双语字幕、拖动进度、参考语音互斥、减少动态与全屏。
- `player.css`：沿用网页设计，桌面字幕侧栏、手机下方字幕。
- `timeline.json`：16 秒与四条解说的对应关系。
- `assets/backgrounds.png`：2172 × 724，左右为空走廊、空教室。
- `assets/characters.png`：1536 × 1024，旧六姿势图集；当前仅复用班主任与小帅的固定姿势，不再用它切换分身姿势。
- `assets/clone-rig.png`：1536 × 1024，按既有人物参考补绘的透明 T 形姿势，用于连续动作的同一组手臂素材。
- `assets/clone-body.png`：1536 × 1024，从同一 T 形姿势精准编辑得到的无手臂身体层，清除直接裁切形成的肩部残片；头部、衣服和比例保持与手臂素材对应。
- `rig-prompt.json`：内置 imagegen 的完整生成提示词。
- `body-prompt.json`：内置 imagegen 去除手臂、整理肩部轮廓的完整编辑提示词。
- `image-prompts.json`：此前两张图集的生成提示词。
- `assets.json`：实际尺寸、格式与哈希。
- `check-continuity.mjs`：实浏览器检查，包括逐帧变化抽样、完整播放与操作验证；`verify.mjs` 为当前检查入口。

所有素材均保存在当前项目并内嵌 HTML，没有网络资源、外部音乐或运行时依赖。没有导出 GIF、WebM、MP4。

## 验证与限制

运行 `node production/book-01/ep-001/animation/verify.mjs`。当前结果位于 `../checks/continuous/verification.json`，关键帧联系表为 `../checks/continuous/contact-sheet.jpg`。

检查会完整播放 16 秒，测量本地浏览器回调的帧间隔；另以每秒 30 帧抽样 481 个 Canvas 画面，检查相邻帧是否存在整幅画面的突然变化。该检查能识别时序跳变，不能代替观众对动作与表演的评价，也不能保证所有设备上的帧率。

当前依然是二维剪纸式动作预演，面部、衣服和身体的连续变形有限，没有口型或正式台词配音。它用于先解决旧版的跳切与位置变化，距离完整动画片的表演质量还有差距。
