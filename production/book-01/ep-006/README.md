# 第六集制作说明

第 006 集《她想要的不是保密费，是十分钟。》交付为 [ep-006.html](../../../episodes/book-01/ep-006.html)。完整剧本、图片与学习词汇均内嵌在单个 HTML，可离线打开。

## 内容

- 8 幅漫画、8 个故事段落、31 段角色对白参考。
- 183 词英文解说，27 组逐句对应的英文与简体中文字幕，以小帅第一人称叙述。原有 22 条中的多句内容按句拆开，英文内容完整保留。
- 5 位相关人物的完整配音设定、内嵌 WAV 参考音频与英文试听文本；苏小满继续“暂定采用”，其余四位“已选定”。
- 5 个新词：aim、target、organise、voluntary、competence。每词有词义、故事例句、中文解释、用法、教材词表位置和回忆问题。
- 2 个主线旧词：goal、challenge。
- 5 个课后到期词回忆：senior、secondary、previous、campus、junior，先回忆再展开答案。
- 1 张结果表：试播原则许可、书面分工与设备检查、待确定的日期。

## 故事与连续性

小帅兑现第五集的约定，午休听完苏小满的提案。她希望让安静的同学也有表达机会，第一期拟从入学第一天得到的帮助谈起。小帅收好秒表，让她讲完整。

老师先许可一次放学后的提案讨论，家长同意并接送分身，老师全程在场。分身展开全天节目表，苏小满只圈出一期十分钟的小格。三人提出愿意承担的工作，分身也承认还需要学习设备操作。

老师原则同意一期十分钟试播，要求先提交书面分工、完成设备检查，之后再确定试播日期。候选分工是苏小满选题与稿件、小帅统筹人员与时间、分身学习声音检查，第七集正式确认。没有现场开机、已经播出或提前完成试机。

午休听提案的十分钟与申请的一期十分钟试播用途不同。标题回扣最初的帮忙，苏小满的诉求是让自己的提案被认真听见；老师与家长早已知情，本集没有新的秘密交易。分身仅从第三格的课后讨论起到校，仍不能代课或日间常驻。

周五搬桌与英语分享的既定安排保留，月底篮球补选仍待申请。

## 解说与字幕

朗读各格“英文解说 · 中英字幕”中的英文行，同一行也作为英文字幕，紧接的中文行为对应中文字幕。按 EN001 至 EN027 与分镜交接，编号和类型标签不朗读；角色对白另收在参考区域。全部解说与人物引语均用小帅固定声音，EN026—EN027 是他的心声。每镜单列解说与角色表演语气。

小帅、分身、苏小满和班主任有角色对白；妈妈仅由解说提及许可与接送，本集没有她的独立台词。画外音、电话和采访回放均沿用对应人物的固定音色。试听供后续视频项目辨认与参考音色，不是本集成片配音；不自动播放，同时只播放一段。

本项目提供文本与图片，配音、剪辑、字幕时间轴和视频导出由另一个项目完成。

- [episode.json](episode.json)：剧本、英文解说、中英字幕、词汇与连续性状态。
- [storyboard.png](storyboard.png)：内置 imagegen 生成的八格原图，887 × 1774 像素。

- [build.py](build.py)：用 Python 标准库嵌入图片、参考音频、字体与文字，输出本集 HTML。

第五集插画作小帅与苏小满参考，第四集插画作分身与老师参考。人物红蓝内搭保持固定，午休画面只有小帅与苏小满。封面取自第四格的长节目表与小红圈。

原图保持不变，HTML 内嵌一份分镜原图供八格共用，通过 CSS 背景定位按原比例显示各格；两张发布封面另行内嵌。正文可选择与复制，单词可跳到对应词卡。图片、字体和 5 段音频均内嵌，无需联网；页面包含少量内联脚本，关闭脚本仍可阅读、展开全文与播放参考音频。支持减少动态效果偏好。
