## 整册故事主线

虚构时间从高一开学延续到学期末。生活篇约覆盖开学后的前五周，运动篇推进到秋季运动活动，庆祝篇在学期末文化展收束。相邻几集可以发生在同一天，不把 72 集压成连续 72 天。

小帅想逃过一次英语发言，生成了一个更爱争取机会的分身。分身替他赢得关注，也带来他没有亲自选择的任务。小帅逐渐学会说出自己的意愿并兑现承诺；分身逐渐理解，帮助别人需要先听对方想做什么，也可以拥有自己的兴趣与贡献。

校园广播把苏小满的目标、小帅的表达练习和分身对关注的渴望连接起来。运动活动让小帅面对真实能力与替补位置；文化展让分身学习等待、倾听，并以独立合作者的身份留下贡献。

| 篇章 | 主要问题 | 阶段结果 |
| --- | --- | --- |
| 001 至 028 生活选择 | 谁能替我答应事情，谁来承担后果 | 小帅亲自表达，三人确认分工，广播项目完成 |
| 029 至 052 运动与健康 | 我不够厉害时，还愿不愿意自己上场 | 小帅接受训练与替补位置，完成真实团队贡献 |
| 053 至 072 庆祝与记忆 | 做得完美，是否等于让别人感到被理解 | 三人办完文化展，分身获得独立署名，关系完成变化 |

第 072 集回扣第一集的 I volunteer!：分身仍会举手，但会先问具体任务。小帅也能亲自完成介绍。第一册的主要矛盾得到结果，第二册可以延续同一组人物。

## 固定人物和分身规则

| 人物 | 起初想要什么 | 容易犯的错 | 第一册的变化 |
| --- | --- | --- | --- |
| 小帅 | 少出丑，保住自己的空闲 | 为了躲一次难题，把决定交给别人 | 能亲口提出需要、拒绝过量任务并兑现自己选的承诺 |
| 分身 | 获得认可，证明自己有用 | 认为多报名、快完成就是帮忙 | 先询问意愿，尊重分工，发现自己的舞台执行与声音制作兴趣 |
| 苏小满 | 让自己的广播策划真正播出 | 遇到被忽略时习惯说算了 | 主动争取时段、署名与表达空间，也接受自己不熟练的一面 |
| 陈野 | 参加比赛并为球队作贡献 | 太习惯独自扛下任务 | 接受休息和队友的支援，学会把机会交给别人 |

分身是本故事唯一的科幻前提：手机一次性生成一个可被所有人看见的实体分身。两人共享生成前的经历，生成后的记忆各自形成；分身也需要吃饭、睡觉、练习和学习。英文表现的差异首先来自敢不敢开口，以及后续练习，能力不会自动从一个人同步到另一个人。

分身保持独立意愿。角色的移动遵守时间和空间，物品只有原来那一份，任务和比赛记录归属于实际参加的人。后续剧情沿用这些规则，不能临时增加瞬移、无限复制或遥控功能来解围。

第 003 集苏小满知道真相；第 004 集家长和班主任知情并安排日常生活，小帅本人承担学生与班长职责，分身参与获准的课后项目。第 007 集项目组知道分工。之后遇到合理询问会说明，第 028 集在广播中完整讲述合作经过。秘密的变化有明确节点。

两人相似的脸和红蓝内搭用于观众识别；角色服装、姓名、物品和所在位置记入每集连续性记录。认出彼此靠具体经历和行为，而非让同学长期忽略同框的两个人。

## 情节合理性和趣味性的标准

每集写作时先完成一条清楚的因果链：角色有一个具体愿望，采取行动，遇到阻碍，作出选择，得到一个实际结果。结尾的新问题从这个结果中长出来。单集先解决一个小问题，再延续人物关系。

创作重点如下：

- **反差有动机。** 分身擅长把任务排满，容易忽略别人的意愿；小帅会退缩，也能观察到流程之外的人。两人各有长处。
- **笑点要看得见。** 例如主角只想回家，分身的竞选表却越填越长；两边连线同时谦让，结果谁也没说话；安慰稿还没读，拿铜牌的队友已经在欢呼。
- **失败留下后果。** 第一集的报名会改变后续日程；放弃初选意味着要等补选；训练记录不会因有分身而补齐。
- **其他人物自己作决定。** 苏小满有自己的节目和署名，陈野有自己的比赛与恢复安排，乡村伙伴有自己的作品和需求。
- **情绪有变化。** 夸张、尴尬、竞争、误会与温暖交替使用。第 070 集让一段回忆自然说完，重点是倾听。
- **背景词服从场景。** 端午、毕业和婚礼可通过文化展、照片和回忆出现；真实时间线仍处于同一学期。pole 按教材的地极义进入北极样信场景。

每批完成后检查：是否连续多集只在改表格、流程或宣传稿；冲突是否又靠分身误读一个词制造。出现重复时，优先改人物选择和场面，保留需要学习的词汇到更自然的位置。

## 每集 HTML 的交付内容

正式路径为 `episodes/book-01/ep-001.html` 至 `ep-072.html`。每个 HTML 包含这一集的全部必要内容，可单独复制、离线打开。

所有新建或重新生成的每集 HTML，均须使用项目内的 `taste-skill`（`design-taste-frontend`）美化后再交付。制作时读取 `.agents/skills/taste-skill/SKILL.md`，按照技能流程完成页面美化和浏览器检查，同时保留全部必需内容与单文件离线使用能力。

| 内容区 | 具体内容 |
| --- | --- |
| 本集信息 | 集数、标题、一句话故事、单元、目标词与预计时长 |
| 完整剧本 | 场景、人物、动作、英文解说、角色对白参考与音效提示 |
| 解说与字幕 | 每个分镜提供英文朗读稿及逐句对应的英文字幕、简体中文字幕；英文解说与英文字幕一致 |
| 人物与配音设定 | 列出本集人物的姓名、性别、年龄感、性格、固定音色特征、参考语音文件名与项目内路径、确认状态；明确英文解说的声音归属与各分镜语气 |
| 插画分镜 | 通常 6 至 8 幅与剧本对应的图片，附镜头编号和图注 |
| 分镜浏览 | 图片按剧本顺序展示；竖屏预演等交互按需提供，不作为每集必需交付项 |
| 学习区 | 本集词义、教材来源、自然例句、先想后揭晓的回忆卡 |
| 连续性记录 | 本集起点与终点、谁知道什么、任务状态、关键道具和下一集承接 |

图片以 data URI 内嵌，样式与必要脚本写在文件中；正文使用可选择的 HTML 文字，方便修订、配音和字幕制作。运行时依赖保存在本文件内，制作时的原图与参考图另行归档。

插画要实际展示本集事件：人物、动作、道具和表情都能与具体镜头对应。手机邀请表、广播麦克风、替补席和相册等关键物件保持前后状态一致。需要准确显示的英文与日期以 HTML 叠字呈现。

单集 HTML 是交接给另一个视频制作项目的内容母稿。本项目交付剧本、图片和学习单词，并明确“英文解说＋中英双语字幕”的制作要求。英文解说栏为实际朗读稿，字幕按编号与分镜逐句对应；角色对白为剧情参考。配音、剪辑、字幕时间轴与成片导出在另一个项目完成。

每个人物先定义声音，再将对应设定写入生成的每集 HTML 的“人物与配音设定”区。声音依据 `voices/book-01/cast.json`、人物目录中的参考音频和试听反馈，标明“已选定／暂定采用／待确认”。同一人物跨集沿用固定音色，画外音、内心独白、电话与采访回放保持身份一致，具体情绪由分镜说明。新增人物先补齐声音设定与参考语音。人物配音资料见 [第一册人物语音](../voices/book-01/README.md)。

## 图片与语言制作规范

正式制作前，先固定小帅、分身、苏小满、陈野的角色参考与常用场景。沿用校园动态漫画方向，优先表现反应、停顿和物件变化。每集的封面也取自本集真实冲突。

每个镜头写清楚人物位置、动作、情绪、前后物件状态，再生成图片。两张长相相同的脸同框时，需要明确红蓝识别与视线关系。人物相貌、内搭、校服和关键道具保持一致。

对白以角色能自然说出口为准。词条按教材原形登记，句子可正常使用时态、复数与词性变化；变化写入学习卡。

英文解说以小帅第一人称串联故事，使用清楚、自然的英语，保留笑点和人物反应。每条英文解说同步作为英文字幕，配一条忠实的简体中文字幕。中文动作说明和对白参考与实际解说稿分区展示。

以下词义与用法需要特别核对：

- congratulation 的常用祝贺语是 Congratulations!
- company 在第 051 集使用公司义。
- feature 在第 023 集用动词义，表达节目以某内容为特色。
- pole 在第 065 集使用地极义；tear 在第 070 集使用眼泪义。
- senior / secondary、immune / system / immune system 等可在同一语境中合并呈现，词表仍保留独立条目。

## 复现与回忆安排

每个新词集安排一次剧情理解和一次本集回忆。后续第 2 集与第 7 集的位置安排 HTML 补充回忆卡；这是按集数排队，实际发布后可按观看日期调整。

视频主线通常只复现 1 至 2 项相关旧词，专门复习集选 6 项。其余到期词放到可展开的课后区域。第 066 集以后仍有跨册到期词，词汇数据保留其下一册偏移集数，不把它们标为已完成复习。

词汇台账分别记录首次分配、同集回忆、后续回忆和实际制作状态。插画里偶然出现英文不自动算完成教学。

每集交付检查六项：

1. **因果**：人物动机明确，时间地点接得上，关键道具来去清楚，本集有结果。
2. **吸引力**：有具体反差或情绪变化，去掉单词标注后仍能看懂并愿意看下去。
3. **英语**：词义与语境准确，对白自然，字幕留出阅读时间，关键表达有回忆机会。
4. **图片**：每幅对应实际镜头，人物可辨，物件与姿态连续。
5. **文件**：一集一个 HTML，离线打开，剧本、图片和学习单词齐全，手机宽度下文字可读，分镜与剧本顺序一致。
6. **台账**：实际词汇、复现与连续性状态同步更新；计划项与已制作项分开。
